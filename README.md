# AssanPay API Console & Testing Workspace

An enterprise-grade internal API testing, debugging, and webhook inspection workspace engineered specifically for the **AssanPay Support and Technical Engineering teams**.

Please see [`app/README.md`](app/README.md) for full architecture documentation, Google OAuth setup guides, database migration instructions, cryptographic signing details, and Vercel deployment procedures.

## Quick Commands (inside `app/`):
```bash
npm install      # Install dependencies
npm test         # Run 36 automated unit, security, and cryptographic tests
npm run dev      # Start Next.js local development server
npm run build    # Run production build
npm run db:seed  # Seed Pakistan & Bangladesh endpoints
```
